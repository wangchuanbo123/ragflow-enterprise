# 项目文档导航

本目录存放帮助开发者理解和维护代码的项目文档。

`docs/` 与 `data/docs/` 用途不同：

- `docs/`：项目架构、代码阅读、实现状态等开发文档。
- `data/docs/`：RAG 要读取和索引的业务知识库文件。

请勿把项目设计文档放入 `data/docs/`，否则会被当作知识库内容建立索引。

## 推荐阅读顺序

1. [项目 README](../README.md)：安装、启动、配置和常用命令。
2. [系统总体说明](系统总体说明.md)：系统总览、服务边界、数据流、部署迁移、使用指南与运维安全的总纲（另有 [HTML 版](系统总体说明.html)，可用 `scripts/build_doc_html.py` 重新生成）。
3. [代码阅读指南](代码阅读指南.md)：入口、分层、调用链和修改位置。
4. [RAG 架构图](RAG架构图.puml)：文档/图谱/代码构建，以及提问、路由、三路检索、召回、融合、重排和生成链路。

## 文档维护约定

- 修改代码后同步更新相关文档；描述能力是否真正可用时，以代码、自动化测试（`pytest -q`，当前 170 项 + 2 subtests）和 README「已知边界」为准。
- `系统总体说明.html` 由 `scripts/build_doc_html.py` 从同名 Markdown 生成，更新 Markdown 后重新运行脚本即可。
