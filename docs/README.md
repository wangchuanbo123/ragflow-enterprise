# 项目文档导航

本目录存放帮助开发者理解和维护代码的项目文档。

`docs/` 与 `data/docs/` 用途不同：

- `docs/`：项目架构、代码阅读、实现状态等开发文档。
- `data/docs/`：RAG 要读取和索引的业务知识库文件。

请勿把项目设计文档放入 `data/docs/`，否则会被当作知识库内容建立索引。

## 推荐阅读顺序

1. [项目 README](../README.md)：安装、启动、配置和常用命令。
2. [代码阅读指南](代码阅读指南.md)：入口、分层、调用链和修改位置。
3. [当前实现状态](当前实现状态.md)：已实现、部分实现、未实现和已知风险。
4. [RAG 架构图](../RAG架构图.puml)：模块及依赖关系。
5. [RAG 问答时序图](../RAG时序图.puml)：一次问答如何经过各个节点。
6. [索引与任务流程图](../索引与任务流程图.puml)：文档同步、任务和 Chroma collection。
7. [知识图谱流程图](../知识图谱流程图.puml)：图谱构建、存储和检索。
